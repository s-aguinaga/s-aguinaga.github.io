# s-aguinaga.github.io

Personal landing page for **Sal Aguinaga, PhD** — AI/ML Engineer & Data Scientist.
Live at <https://s-aguinaga.github.io>.

- Static single page (`index.html`); no build step.
- Featured repos are listed in the `REPOS` array near the bottom of `index.html`.
  Stars, forks, language, and last update load live from the GitHub API, with a saved
  snapshot used if the API is unavailable.

## Legacy site

The previous Hugo blog (2016–2019) is preserved on the [`legacy`](../../tree/legacy)
branch and the `legacy-2019` tag.
